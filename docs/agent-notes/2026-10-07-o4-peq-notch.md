# O4 static feedback notches and the generalized PEQ writer

Authority: operator ruling `dec-autonomous-muted-bench-20261007` (all live
speakers muted; ship and converge; keep read-before-write, rollback snapshot,
exact readback, real tests). Static live-path feedback suppression: DSP1124P
single-shot then lock on the vocal channel, measured notches on the DCX O4 PEQ.

## What changed

- `dcx-core::layout`: the pinned MIT DuinoDCX `00b9d70` `outputLocations[6][74]`
  table, transcribed mechanically, with the 7-of-8 packing rule asserted for all
  444 rows and equality with the earlier hand-reviewed O1/PEQ9 and O4-mute
  offsets (and the six mute offsets the practice-route diagnostic reads).
- The snapshot projection and inverse use one closed allowlist: PEQ on/off,
  band count, and the nine bands on every output, plus the O4 mute. Values are
  checked against device domains in both directions; apply admission refuses
  boosts. Rollback actions are the baseline values in reverse order.
- Dump1 keeps its baseline modulo-128 trailer balance (named hypothesis; the
  Dump0 rule is named-device observed). This changes the projected trailer for
  the O4 mute write too. A wrong guess forces only the bound rollback.
- `dcx.desired-profile/v2` (one output's cut-only PEQ actions); `control diff`
  accepts v1 or v2 and adds `desired_profile_schema` to its envelope.
- `dcx-core::feedback`: digest-bound measurements (frequency list, REW Generic
  EQ) and a pure O4 notch planner. `dcxctl feedback import|inspect|plan|
  desired-profile`. Design and policy: `docs/feedback-suppression.md`.
