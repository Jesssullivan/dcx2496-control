## What `//:linux_suite` leaves out of `//:check`

`//:linux_suite` runs a smaller set than `//:check`. A green GF validate is
not parity with `just check` or `just fixtures`. These eight `//:check`
members are sh_tests that read the host PATH, so they stay out of the suite.
They still need `--config=host-gates`.

| `//:check` member | Kind |
|---|---|
| `:fixture_contract` | sh_test, host PATH |
| `:feedback_pipeline` | sh_test, host PATH |
| `:routing_pipeline` | sh_test, host PATH |
| `:write_pipeline` | sh_test, host PATH |
| `:profile_pipeline` | sh_test, host PATH |
| `:apple_feedback_fixture_parity` | sh_test, host PATH |
| `:apple_linkage_tests` | sh_test, host PATH |
| `:bazel_frontdoor_rejections` | sh_test, host PATH |

The dcxctl fixture and pipeline contracts are among them, so a GF run on
`//:linux_suite` does not catch a break in those.
